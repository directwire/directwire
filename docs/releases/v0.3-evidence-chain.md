# Evidence chain release — v0.3

> 把这一周的四块重资产钉成里程碑：net-sim 模拟网、fuzz 框架、IETF I-D、
> BPF 实机验证。这张表的纪律来自 CODE_OF_CONDUCT 的
> **"Reproducibility as policy"**——白皮书里每个数字都必须带测量装置：
> 要么 loopback 基准、要么确定性网络模拟、要么真内核、要么明确写待办。
> 没有一个数字是 PPT。

## 这一版入库的资产

1. **net-sim 确定性网络模拟器**（`docs/benchmarks/net-sim-v0.2.md`）
   —— 真实 socket + 种子化中继代理注入延迟/丢包，同一份代码路径，
   网络部分是合成的。单机 loopback 的 80% 替身。
2. **fuzz 框架**（`fuzz-harness` + `fuzz/`）—— 确定性引擎 + libFuzzer 平移，
   5 目标，PR 冒烟 10 分钟 / nightly 长跑 2 小时，崩溃自动落盘上传。
3. **IETF I-D** `draft-directwire-agent-transport-00` —— RFC 7991 v3 XML，
   纯 python 构建，idnits 预检进 CI。
4. **xdp-edge BPF 实机验证** —— GitHub Actions 在 runner 真内核上完成
   编译 → 加载 → 全数据面测试，不依赖任何人的本机设备。

## 还是待办（诚实边界，白皮书 Honest limits 全量继承）

| 待办 | 现状 |
|---|---|
| **多机真实测试床** | net-sim 是 80% 替身；真实网卡/RTT 抖动/拥塞梯度待多机实测 |
| **xdp-edge 真内核吞吐/延迟** | 真内核目前只证了正确性（环回链 + stats）；5 Mpps 是模拟器数字 |
| **I-D 提交 datatracker** | 作者块是匿名组织占位（`draft-directwire@directwire.example`），正式投稿待做 |
| **p2p-mesh 真实对称 NAT 打洞** | 目前只有 loopback/模拟验证，真实对称 NAT 环境未测 |
| **xdp-edge 控制面真实流量探活** | 探活是虚拟时钟驱动，真实业务流量下未验证 |
| **国密证书合规** | MLPS 评估与商用密码认证是明确红线，生产须换认证模块 |
| **homa-rpc 描述符级零拷贝泵送** | 实测（2026-08-16 mix_probe）：io_loop 锁内泵送**非争用点**（持锁 16.9µs/batch、等锁 0.6µs）；~170µs/方向实为每分片 `Packet::encode` 的 memcpy（≈250ns×874≈200µs/1MiB）。真零拷贝 sendmsg 是正解，但 ~20% 收益、改核心路径，随多机测试床待办 |
| **homa-rpc io_uring/AF_XDP 旁路 + 多线程 IO** | 长消息并发仍单 IO 线程，白皮书自认最弱层 |

## 复现命令

```bash
# 全部测试（≈180 个，CI 同款）
cargo test --workspace --all-features

# net-sim 网络条件探测（证据 #4–#7）
cargo run --release -p homa-rpc --example net_probe

# fuzz 冒烟（5 目标，本机 10 分钟）
cargo install cargo-fuzz --locked && cd fuzz && cargo fuzz run homa_transport -- -max_total_time=600

# xdp-edge 真内核数据面验证（Linux）
git fetch origin && git checkout v0.3
# 自动跑在 GitHub Actions：.github/workflows/bpf.yml
```
